# حاسبة الذهب

حاسبة عربية تجلب سعر الذهب العالمي تلقائياً وتعرض سعر الجرام بالريال السعودي لعيارات 24 و22 و21 و18، وتحسب قيمة الذهب حسب الوزن مع المصنعية وضريبة القيمة المضافة.

**تجربة الموقع:** https://narjes455.github.io/gold-calculator/

## المميزات
- تحديث تلقائي لسعر الذهب كل 10 دقائق من [gold-api.com](https://gold-api.com)
- تحويل سعر الأونصة بالدولار إلى سعر الجرام بالريال (3.75 ريال للدولار)
- حساب القيمة حسب الوزن والعيار، مع المصنعية وضريبة 15% اختيارياً
- حفظ آخر سعر في المتصفح، وإمكانية إدخال السعر يدوياً
- واجهة عربية تدعم الجوال والوضع الليلي
